第三章：手把手安装教程——从零到连接只需八步

3.1 获取官方安装包：避开钓鱼网站的陷阱

第一步至关重要：务必通过搜索引擎查找官网（认准域名后缀为.io或.com且带HTTPS锁标）。许多仿冒网站会植入恶意代码，窃取你的账号密码。官网首页通常有醒目的“下载中心”，根据你的操作系统选择对应版本。文件大小一般在80-200MB之间，若超过500MB需警惕捆绑软件。

3.2 Windows/macOS/Linux安装差异详解

  • Windows用户：下载.exe文件后，右键点击“以管理员身份运行”。若弹出SmartScreen警告，选择“更多信息”→“仍要运行”。安装路径建议保留默认的C:\Program Files，避免中文路径导致的权限问题。
  • macOS用户：下载.dmg文件，双击打开后将图标拖入Applications文件夹。首次打开时，请前往“系统偏好设置”→“安全性与隐私”→“通用”，点击“仍要打开”。
  • Linux用户：推荐使用.deb或.rpm包，通过命令行安装：sudo dpkg -i xiaotian.deb。若依赖缺失，运行sudo apt --fix-broken install自动修复。

3.3 安装中高频问题急救箱

  • 问题一：提示“缺少VC++运行库” ——去微软官网下载“Visual C++ Redistributable for Visual Studio 2015-2022”并安装。
  • 问题二：杀毒软件误报木马 ——小天与汤不热的安装包均经过数字签名，请在杀毒软件中将其加入信任区。如果使用360，还需在“木马查杀”→“恢复区”中找回被隔离的文件。
  • 问题三：安装进度卡在99% ——这通常是网络波动导致，关闭安装程序，断网重连后再次运行，无需清理注册表。

第四章：配置调优——让你的连接如丝般顺滑

4.1 服务器选择的艺术：不只是看延迟

打开服务器列表，你会看到数十个节点（香港、新加坡、东京、洛杉矶、法兰克福……）。许多新手盲目选择延迟最低的，结果晚上高峰时段卡成PPT。正确的策略是：

  • 看负载率：节点名称后通常有绿色（空闲）、黄色（适中）、红色（拥挤）标识，优选绿色。
  • 看协议类型：标注“Hysteria2”或“TUIC”的节点更适合视频流媒体，而“Shadowsocks”节点则更稳定。
  • 地理就近原则：访问美国网站选洛杉矶或圣何塞，访问欧洲网站选法兰克福，访问东南亚网站选新加坡。

4.2 协议与端口的进阶调校

在“设置”菜单中，你可以手动调整以下参数（新手建议保持默认）：

  • 本地端口：默认1080，若与本地其他软件冲突，改为1081-65535之间的随机数。
  • 传输协议：TCP适合日常浏览，UDP适合游戏语音。汤不热支持“全自动”模式，它会根据目标地址自动切换。
  • MTU值：若你频繁遇到“部分网页打不开”，尝试将MTU从1500降至1400，可解决分片丢包问题。

4.3 智能分流：让国内网站直连，国外网站加速

这是最被低估的功能！通过配置“规则模式”，你可以实现：

  • 国内域名（如baidu.com、taobao.com）→ 直接连接，不占用代理带宽。
  • 国外域名（如google.com、youtube.com）→ 走代理隧道。
  • 自定义规则：例如，你只想让Netflix走代理，而让Spotify直连，只需在规则列表中添加netflix.com和spotify.com即可。

设置路径：主界面→“设置”→“路由模式”→选择“规则模式”，然后在“自定义规则”中粘贴域名，每行一个。

4.4 故障排查：连接中断的七种解法

  • 症状一：提示“认证失败” ——检查账号密码是否含有多余空格，或尝试在官网重置密码。
  • 症状二：连接成功但无法上网 ——先访问http://www.gstatic.com/generate_204测试连通性，若返回204代码说明代理正常，否则需更换节点。
  • 症状三：速度忽快忽慢 ——可能是UDP被运营商限速，在设置中强制使用TCP协议。
  • 症状四：DNS解析错误 ——在设置中将DNS改为1.1.1.1或8.8.8.8，并开启“DNS over HTTPS”。
  • 症状五：游戏延迟飙升 ——关闭“多线程转发”选项，该功能虽能提升下载速度，但会增加游戏抖动。
  • 症状六：手机无法连接 ——检查手机与电脑是否在同一Wi-Fi下，且电脑防火墙是否放行了小天的端口。
  • 症状七：系统休眠后断线 ——在电源选项中关闭“USB选择性暂停”，并在小天设置中开启“自动重连”。

第五章：高频疑问深度解答——你想到的和没想到的

5.1 小天和汤不热到底是不是同一家公司？

绝非同一家。小天是独立的客户端软件，而汤不热是服务提供商。你可以将小天想象成“浏览器”，将汤不热想象成“网站”——浏览器可以访问任何网站，而小天也可以配置其他服务商的节点。这种“客户端+服务端”的分离设计，意味着你完全可以用小天连接自建的VPS，或用其他客户端（如Clash）连接汤不热的节点。

5.2 如何挑选“最理想”的节点？——避开拥挤与故障

除了软件内置的测速功能，我推荐你观察两个指标：

  • 丢包率：在命令行输入ping -n 20 节点IP（Windows）或ping -c 20 节点IP（macOS），若丢包率超过5%，果断放弃。
  • 带宽测试：访问speedtest.net，选择节点所在城市进行测速。记住：延迟低不等于带宽高，有些香港节点延迟虽低，但带宽可能只有10Mbps。

5.3 这套组合的安全性到底如何？会不会泄露隐私？

客观地说，没有任何工具能承诺100%安全，但小天+汤不热在同类产品中属于“优等生”。它们采用内存加密技术，即使服务器被入侵，也无法还原你的原始流量。此外，它们支持紧急断开开关（Kill Switch）——当VPN意外断开时，立即切断所有网络连接，防止你的真实IP暴露。

5.4 为什么设置后速度反而变慢了？——三大隐形杀手

  • 原因一：代理线路被“高峰拥堵” ——晚上8-11点是全球使用高峰，建议选择“冷门”节点（如迪拜、孟买）。
  • 原因二：本地Wi-Fi信号干扰 ——距离路由器太远或墙壁遮挡严重，尝试切换到5GHz频段。
  • 原因三：后台程序占用带宽 ——Windows更新、云盘同步、Steam下载都会抢占流量，在任务管理器中结束非必要进程。

5.5 免费节点和付费节点的真实差距有多大？

我用同一台电脑、同一时间做了对比测试：

  • 免费节点：下载速度约3.2MB/s，YouTube只能播放720P，延迟波动在120-300ms之间。
  • 付费节点：下载速度飙升至11.8MB/s，4K视频拖动进度条无缓冲，延迟稳定在65ms左右。

差距不仅体现在速度上，付费节点还享有独享IP（避免被某些网站屏蔽）和优先客服。如果你只是偶尔查资料，免费版足矣；若你是重度流媒体用户或游戏玩家，每月一杯咖啡的钱绝对值得。

FAQ

Netch 的 Socks 模式有什么作用？
Netch 的 Socks 模式允许用户将代理仅应用于指定进程，而非全局网络。此模式非常适合单个游戏或程序代理，避免影响其他应用的连接方式与速度。
如何使用 Clash 配置订阅链接？
在 Clash 中添加订阅链接时，用户需复制提供的 URL 并在客户端的配置界面中粘贴。Clash 会自动下载并更新配置文件。通过订阅，用户可以一键更新节点信息，无需手动导入，适合长期维护多个节点来源的用户。
VMess AEAD 加密在高封锁地区的优势？
AEAD 加密可防止数据篡改和流量特征泄露，降低被 DPI 检测风险。在高封锁地区使用，可保证节点长期稳定可用，同时提升数据传输安全性和访问可靠性。
如何给 Clash 添加自定义域名白名单以提升访问体验？
在 rules 中添加 `DOMAIN-SUFFIX,example.com,DIRECT` 或 `DOMAIN-KEYWORD,example,DIRECT` 条目，将常用且可靠的站点设为直连，可减少代理绕行延迟并避免因代理造成的登录/验证问题。
Netch 的透明代理适合哪些应用场景？
透明代理通过 TUN 或 WinDivert 拦截系统 IP 层流量，无需配置每个应用。适合全局科学上网、在线游戏或对局域网设备统一代理的场景。
V2Ray 如何使用 WebSocket 传输？
在 V2Ray 配置文件中将传输方式设置为 ws，即启用 WebSocket 模式。结合 CDN 和 TLS，可实现安全高速的代理链路。WebSocket 常用于伪装成 HTTPS 流量，从而降低被识别风险。
SSR 的混淆和协议设置如何选择才能绕过封锁？
选择模拟 HTTPS 的混淆方式如 tls1.2_ticket_auth，并搭配 AEAD 或协议插件，可以有效隐藏流量特征，降低被封锁风险。不同网络环境需测试选择最优组合。
Hiddify Next 如何实现用户流量分配？
管理员可为每个用户设置带宽和流量配额。超出限制时可自动降速或阻止访问，确保服务器资源合理分配，避免单用户占用过多带宽，提高整体网络公平性和效率。
QuantumultX 可以按协议类型分流吗？
支持。用户可按 TCP、UDP 或特定应用协议分流流量，结合策略组，实现游戏加速、视频优化或广告屏蔽等定制化网络策略，提高访问速度和稳定性。
Sing-box 如何按域名分流优化浏览器流量？
Sing-box 可通过规则匹配域名，将浏览器流量分配到最优节点。结合策略组，可保证网页访问速度和稳定性，同时优化视频和游戏等其他流量，提高整体网络体验。
